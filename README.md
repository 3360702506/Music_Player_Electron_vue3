# Electron 音乐播放器

一个使用 Vue 3 和 Electron 构建的功能丰富的桌面音乐播放器。

## 特性

- 🎵 本地音乐播放 (MP3, FLAC, WAV, AAC, OGG)
- 📊 音乐库管理与元数据提取
- 📃 LRC 格式歌词支持
- 📋 播放列表管理
- ⭐ 收藏夹功能
- 🎨 可自定义主题 (浅色/深色/自动)
- 📱 系统托盘集成
- ⌨️ 全局键盘快捷键
- 🌈 音频可视化器
- 🪟 悬浮歌词窗口
- 📊 播放历史记录

## 安装与运行

进入 `musicplayer` 目录，然后按照以下步骤操作：

### 环境准备

- Node.js (>= 14)
- npm

### 安装依赖

```bash
npm install
```

### 开发模式运行

```bash
npm run electron:dev
```

### 构建应用

```bash
npm run electron:build
```

## 使用说明

### 添加音乐

1. 点击侧边栏的"扫描音乐"以选择包含音乐文件的文件夹。
2. 应用程序将扫描支持的音频文件并提取其元数据。
3. 你的音乐将出现在"音乐库"视图中。

### 播放音乐

- 点击任何曲目即可播放。
- 使用底部的播放器控件来控制播放。
- 使用音量滑块调节音量。

### 播放列表

- 从"播放列表"视图创建播放列表。
- 从"音乐库"或其他视图将曲目添加到播放列表。
- 通过添加或删除曲目来管理播放列表。

### 设置

从"设置"视图访问各种设置：
- 主题定制
- 音频可视化器设置
- 悬浮歌词设置
- 全局快捷键配置

## 键盘快捷键

- 播放/暂停: `Ctrl+Alt+P`
- 下一首: `Ctrl+Alt+Right`
- 上一首: `Ctrl+Alt+Left`

这些快捷键可以在"设置"视图中自定义。
